## 第11段階で追加された加工経路

| 作成物 | 必要素材 |
| --- | --- |
| キャラのハンコ 1個 | こねこね粘土 1個 + 手形 3個 |
| こねこね粘土 1個 | EGOブロック 2個 + やわらか粘土 1個 |
| EGOブロック 1個 | 曲がったもの 3個 |
| 手形 1個 | やわらか粘土 3個 |

キャラのハンコ1個の最終換算は、曲がったもの6個とやわらか粘土10個です。1研究ではキャラのハンコを12個使うため、曲がったもの72個とやわらか粘土120個が必要です。
